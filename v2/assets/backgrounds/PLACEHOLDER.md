# 🖼️ Coloque sua imagem aqui!

Você precisa colocar uma imagem de fundo nesta pasta:

**Nome esperado:** `fundo.jpg` (ou `.png`)
**Resolução:** 1920x1080 (proporcional OK)
**Formato:** JPEG ou PNG

## Como fazer:

1. Coloque a imagem nesta pasta
2. Rename para `fundo.jpg`
3. Recarregue a página

A imagem será redimensionada automaticamente para caber no canvas.

---

**Dica**: Se tiver a imagem da v1, pode reutilizar!
